PAGE — the basics

PAGE is where you describe the content and structure of what appears on a page.

1. Start the file

Put page on the first line. This tells MoLang that the file contains page content.

page

h1. Hello MoLang
p. I am learning from zero.

2. What is an element?

An element is a named piece of the page. For example, h1 is a main heading and p is a paragraph. Put a dot directly after the element when you want to put text on that same line.

page

h1. My first title
p. This is a paragraph.
The dot belongs to the MoLang syntax. Keep it attached to the element or directly after the final attribute.

3. What does indentation mean?

Indentation shows that one element belongs inside another. When indentation returns to an earlier level, the previous nested block ends.

page

section
    h1. Welcome
    p. Everything inside here belongs to the section.

footer
    p. The section is now finished.

Attributes

An attribute gives extra information or configuration to an element. Attributes are written after the element name.

Basic pattern

element attribute="value". Text

Some attributes are switches. For example, required means the field must be filled in.

input type="email" placeholder="name@example.com" required
  • id — gives one element a unique name.
  • class — gives an element one or more reusable labels for styling or scripting.
  • title — provides extra descriptive text.
  • hidden — starts the element hidden.
  • data-* — stores your own custom data.

Useful input types

Text, email, password, number, date, time, checkbox, radio, file, range, color, search, url, and submit are common choices. The type changes what kind of value the control is designed to accept.

  • src — image location.
  • alt — text description when the image cannot be seen.
  • width / height — intended dimensions.
  • loading — controls loading behavior.

STYLE — the basics

STYLE controls appearance. Indentation places properties inside a selector block.

style

card
    padding: 20px
    border-radius: 16px
    background: white

Selector, property, value

Selector chooses what to style. Property chooses what to change. Value is the setting you give that property.

Selectors

SelectorSelects
pAll paragraph elements.
.cardElements with class card.
#menuThe element with id menu.
*Everything.
article pParagraphs inside article.
article > pDirect paragraph children.
a:hoverA link while hovered.
style

.card
    padding: 20px

#menu
    display: flex

button:hover
    transform: scale(1.05)

Flexbox

Flexbox is useful for arranging items in one direction: a row or a column.

style

.menu
    display: flex
    flex-direction: row
    justify-content: space-between
    align-items: center
    gap: 16px
    flex-wrap: wrap
  • flex-direction — row or column direction.
  • justify-content — spacing along the main direction.
  • align-items — alignment across the main direction.
  • gap — space between items.
  • flex-wrap — allows items to move to another line.
  • flex-grow / flex-shrink / flex-basis — control how items use available space.

Grid

Grid is excellent for two-dimensional layouts with rows and columns.

style

.gallery
    display: grid
    grid-template-columns: repeat(3, 1fr)
    gap: 20px

Useful properties include grid-template-columns, grid-template-rows, grid-column, grid-row, gap, and grid-template-areas.

Colors and visual styling

style

.card
    color: white
    background: linear-gradient(135deg, #7c3aed, #06b6d4)
    border: 1px solid #ffffff33
    border-radius: 20px
    box-shadow: 0 20px 50px #00000033
    opacity: 0.95

Learn these groups together: color, background, border, border-radius, box-shadow, opacity, filter, and outline.

Typography and spacing

style

.title
    font-family: Arial, sans-serif
    font-size: 42px
    font-weight: 700
    line-height: 1.2
    letter-spacing: -1px
    text-align: center

.text
    margin: 0
    padding: 16px

Important text properties: font-family, font-size, font-weight, font-style, line-height, letter-spacing, word-spacing, text-align, text-decoration, text-transform, and white-space.

Motion

style

.button
    transition: transform 0.2s ease

.button:hover
    transform: translateY(-2px)

Use transition for smooth changes. Use transform for moving, scaling, rotating, or skewing. For repeated or complex motion, use animation and keyframes.

Responsive design

Responsive design means your page adapts to different screen sizes.

style

.container
    width: 90%
    max-width: 1200px

@media (max-width: 700px) {
    .gallery {
        grid-template-columns: 1fr;
    }
}

Useful units include px, %, rem, em, vw, vh, and fr. Start with a flexible layout, then use media queries when a specific screen size needs a change.

SCRIPT — the basics

SCRIPT gives instructions and reacts to what happens.

script

print "Hello, MoLang"

message = "Welcome"
count = 0

Use print to output information for debugging and learning. Variables let you store values.

Variables

script

name = "Alex"
score = 10

score = score + 5
print score
  • A variable has a name and a value.
  • Use a clear name that describes what the value means.
  • You can change a variable later by assigning a new value.

Data types

TypeExampleMeaning
String"Hello"Text.
Number42 or 3.14A numeric value.
BooleanTrue / FalseTrue-or-false value.
Empty valueNoneNo value.
Array[1, 2, 3]An ordered collection.
Object{ name: "A" }A collection of named values.

Operators and expressions

script

total = 10 + 5
half = total / 2
power = 2 ** 3

if total > 10 and not False
    print "Large enough"

Arithmetic: +, -, *, /, %, **. Comparisons: ==, !=, >, <, >=, <=. Logic: and, or, not.

Conditions

script

score = 85

if score >= 90
    print "Excellent"

elif score >= 50
    print "Passed"

else
    print "Try again"

if checks the first condition. elif gives another condition if earlier ones failed. else runs when no previous condition was true.

Loops

script

for i in range(5)
    print i

for i in range(10, 0, -1)
    print i

items = ["A", "B", "C"]

for item in items
    print item

range(end) starts at 0. range(start, end) uses a custom start. range(start, end, step) also controls the step. Use break to stop a loop and continue to skip to its next iteration.

Functions and async work

script

def greet(name)
    print "Hello " + name

greet("Alex")

async def loadData()
    await fetchData()
    print "Finished"

A function groups reusable instructions. Parameters receive information when the function is called. return sends a result back. Async functions can use await for asynchronous work.

script

try
    riskyWork()

except error
    print error

finally
    print "Always finished"

Page control

These commands let SCRIPT find and change things on your page. You do not need to learn the generated language to understand them.

get "#title"Find an existing page item.
set "#title" text to "Welcome"Change visible text.
set "#box" html to "..."Change inner content.
set "#email" value to "..."Change an input value.
set "#box" style color to "red"Change one visual setting.
show "#menu"Make an item visible.
hide "#menu"Hide an item.
remove "#item"Remove an item.
focus "#email"Put keyboard focus on a control.
script

set "#title" text to "Welcome!"
add class "active" to "#menu"
toggle class "dark" on "body"
script

create div as card
card.textContent = "New card"
append card to "#container"

Class commands: add class, remove class, and toggle class. Creation commands: create and append.

Events

An event is something that happens, such as a click, typing, a change, or form submission.

script

on "#button" click
    print "Button clicked"

on "#email" input as event
    print event.target.value
clickThe user presses and releases a pointing device button.
inputAn input value changes while editing.
changeA value is committed or changed.
submitA form is submitted.
keydown / keyupA keyboard key is pressed or released.
mouseover / mouseoutThe pointer enters or leaves.
