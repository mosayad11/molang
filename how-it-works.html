MoLang Documentation

Learn MoLang from zero.

You do not need to know HTML, CSS or JavaScript before learning MoLang. This guide starts from the beginning and explains what pages, elements, attributes, styles and scripts are, how to write them in MoLang, and how your MoLang code becomes real web code.

01 — GETTING STARTED

What is MoLang?

MoLang is a language for creating web pages. When you write MoLang, your code is translated into the languages that web browsers understand.

Page

Describes the content and structure of a web page, such as headings, paragraphs, images and sections.

Style

Controls how your page looks: colors, spacing, sizes, backgrounds, borders and more.

Script

Adds behavior and logic to the page, such as responding to clicks and changing content.

Real web code

At run time, MoLang converts your code to HTML, CSS and JavaScript.

The important idea You write simpler MoLang syntax. MoLang handles the translation into real browser code for you.
02 — FILE TYPE

Every file tells MoLang what it is.

The first thing in every MoLang file must tell the translator what type of code you are writing.

There are currently three main types:

File types 
page

style

script

page

Use page when you want to create the structure and content of a web page.

style

Use style when the file contains visual styling.

script

Use script when the file contains JavaScript logic.

Required A MoLang file must begin with one of these types. If it does not, the MoLang extension can report an error because the translator does not know what kind of code it should generate.
03 — PAGE

Create your first page.

A page is made from elements. An element represents something on the page.

For example, a heading, paragraph, image, button, section or link can all be elements.

index.mo 
page.
    head.
        title. My page

    body.
        h1. Hello 👋
        p. Welcome to my first page

This creates a page with a title, a large heading and a paragraph.

You do not need to write html

You may notice that the example starts directly with head and body.

MoLang automatically creates the outer HTML structure around your page, so you do not need to manually write an html element.

04 — ELEMENTS

Elements are the building blocks.

Think of a page as a tree. Some elements contain other elements, while some simply contain text or point to a resource such as an image.

h1

A large main heading.

p

A paragraph of text.

img

Displays an image.

main

Holds the main content of a page.

The dot

When you create an element that may contain text or children, you finish the element declaration with a dot.

Element examples 
h1. Hello

main.
    p. Hello from inside main

In the first example, Hello is the value of the heading.

In the second example, main contains another element underneath it.

Elements that do not need children

Some elements do not normally contain other elements. An image is a good example.

Image 
img src="mosayad.jpg"

Because the image does not need children, the final dot is not important here.

05 — INDENTATION

Indentation tells MoLang what belongs where.

Indentation means moving a line to the right. In MoLang, indentation is not just for appearance. It describes the relationship between elements.

Parent and children 
body.
    main.
        h1. Hello
        p. Welcome

Here, main is inside body.

The h1 and p are inside main.

This parent/child relationship is created entirely by indentation.

Easy way to think about it If a line belongs inside the line above it, move it one indentation level to the right.
06 — ATTRIBUTES

Give elements more information.

An attribute is additional information attached to an element.

For example, an image needs to know which image file it should display.

Image source 
img src="mosayad.jpg"

Here, src is an attribute.

Its value is "mosayad.jpg".

Classes

A class gives an element a name that can later be used when styling it.

Class attribute 
main class="card".
    h1. Hello
    p. Welcome

The main element now has the class card.

Later, you can style .card in a style file.

07 — TEXT

Put text directly after the dot.

If an element has one simple text value, you can place that value directly after the dot.

Text 
h1. Welcome to MoLang

p. This is a paragraph

p. مرحبا بالعالم

The text can be English, Arabic or other normal text supported by your file.

08 — STYLE

Make your page look the way you want.

A style file controls the appearance of your page.

It can change colors, backgrounds, spacing, borders, sizes and many other visual properties.

Start the file with style.

style.mo 
style

body
    background: linear-gradient(90deg, #ff7e5f, #feb47b)

body h1
    color: red
    background-color: #000

body h2
    color: blue

body p
    color: black

.header-section
    border-radius: 40px

Selectors

A selector tells MoLang which element or group of elements you want to style.

body

Selects the whole page body.

body h1

Selects h1 elements inside body.

.card

Selects elements with class="card".

#header

Selects an element with the matching ID.

Properties

Properties describe what you want to change.

Style properties 
color: red
background-color: black
padding: 40px
border-radius: 20px

You do not need curly braces around the properties and you do not need a semicolon after every property.

Put the properties below the selector using indentation.

09 — SCRIPT

Add behavior with scripts.

Script files contain the logic that makes your page interactive.

For example, scripts can react when a user clicks a button, update text or perform calculations.

At the moment, MoLang script files use normal JavaScript syntax.

script.mo 
script

const button = document.querySelector("button");

button.addEventListener("click", function () {
    alert("Hello from MoLang!");
});
Script syntax is evolving For now, only the first script declaration is MoLang-specific. The JavaScript code below it is written normally. A simpler MoLang script syntax can be introduced in future versions.
10 — CONNECTING FILES

Split your project into multiple files.

A real project does not need to keep everything inside one file.

You can create a page file, a style file and a script file and connect them together.

Add a stylesheet

Inside the page head 
head.
    link rel="stylesheet" href="style.mo"

MoLang can also link to a normal CSS file:

Normal CSS 
link rel="stylesheet" href="style.css"

Add a script

MoLang script file 
script src="script.mo".

Or use normal JavaScript:

JavaScript file 
script src="script.js".
Notice the final dot When writing the script element in a page, keep the final dot after it. This tells the translator that the line represents an element declaration rather than plain text.
11 — REAL WEB CODE

Your MoLang becomes real web code.

MoLang is designed to generate the web languages that browsers understand.

This means you can write your project in MoLang and still access the generated HTML, CSS and JavaScript when you need them.

Page example

MoLang 
page.
    head.
        title. My page

    body.
        main class="card".
            h1. Hello 👋
            p. مرحبا بالعالم
Generated HTML 
<html>
    <head>
        <title>My page</title>
    </head>

    <body>
        <main class="card">
            <h1>Hello 👋</h1>
            <p>مرحبا بالعالم</p>
        </main>
    </body>
</html>

Style example

MoLang 
style

body
    color: #18202b
    padding: 40px
Generated CSS 
body {
    color: #18202b;
    padding: 40px;
}

Preview your project

Use the MoLang tools inside VS Code to run or preview your project.

View the generated code

If you want the real HTML, CSS or JavaScript generated from your MoLang file, use the MoLang: View Code command.

You can then copy the generated code and use it in another normal web project if you want.

1

Open your MoLang file

Open the page, style or script file you want to convert.

2

Run View Code

Open the VS Code Command Palette and choose MoLang: View Code.

3

See the generated code

MoLang shows the real web code created from your file.

4

Copy it anywhere

Copy the generated code and place it in a normal HTML, CSS or JavaScript project.

12 — FIRST PROJECT

Build a complete small project.

Let's combine everything you've learned into a simple MoLang website.

Step 1 — index.mo

index.mo 
page.
    head.
        title. My first MoLang website
        link rel="stylesheet" href="style.mo"

    body.
        main class="card".
            h1. Welcome 👋
            p. This page was written with MoLang
            img src="mosayad.jpg"

        script src="script.mo".

Step 2 — style.mo

style.mo 
style

body
    background: #080b12
    color: white
    padding: 40px

.card
    padding: 30px
    border-radius: 20px
    background-color: #18202b

.card img
    width: 200px

Step 3 — script.mo

script.mo 
script

console.log("My MoLang project is running!");

Project structure

Files 
my-project/
│
├── index.mo
├── style.mo
├── script.mo
└── mosayad.jpg

Your page file describes the structure, your style file controls the appearance, and your script file contains the logic.

MoLang connects these pieces and converts them into the web code needed to run the project.
